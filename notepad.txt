F2FS Background GC (BGGC) – Copy-Offload Validation
1. Objective
Validate the current F2FS garbage-collection copy-offload implementation during Background Garbage Collection (BGGC) on the UFS device.
The validation is intended to confirm:
BGGC selects victim segments and migrates valid data blocks.
F2FS invokes the copy-offload path for migrated data blocks.
The copy request is issued as a 4-KiB device-copy operation in the current implementation.
Source and destination physical block addresses (PBAs) can be correlated from F2FS logs.
The SCSI/UFS layer receives the copy command on UFS LUN 6.
The copy command completes successfully.
Consecutive migrated blocks show sequential source and destination PBAs.
The current implementation performs one copy-offload operation per migrated 4-KiB block; batching/optimization is intentionally outside the scope of this validation.
