fg_append_full
Sequentially append data to an aged filesystem filled to approximately 90%. Measures throughput, elapsed time and write latency.

fg_random_overwrite
Perform random 4 KiB overwrites on a nearly full filesystem. Measures IOPS, throughput and write latency.
Out-of-place updates should create allocation pressure, potentially triggering foreground GC. The test requires verified foreground GC activity.

fg_parallel_writers

fg_ioctl_sync_gc
Explicitly invoke F2FS_IOC_GARBAGE_COLLECT with sync=1, repeatedly requesting synchronous GC. Measures calls, successful ioctls, blocks moved and latency.
Synchronous GC should execute and be observable through the foreground GC counters. The test should finish when no more suitable victims remain or the configured limit is reached.

fg_enospc_recovery
Fill the filesystem to ENOSPC, create churn, delete approximately 20% of the files and attempt new writes. Measures recovery throughput and latency.
The initial fill should reach ENOSPC, deleting files should make space available, and subsequent writes should recover without ENOSPC. Foreground GC activity must also be verified for this scenario.
