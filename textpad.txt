Framework Execution Lifecycle

 [START: Host Initialization]
               |
               v
  Host runs run_on_device.ps1
  - Connects to device over root ADB
  - Deploys test files to target dir
  - Parses /proc/mounts to find $MNT
  - Exports $F2FS_NODE="sdg"
               |
               v
 [STEP 1: Test Driver Setup]
               |
               v
  Target runs run_all.sh
  - Loops over execution modes ($MODES)
  - Records device configuration data
  - Forwards execution to target scripts
               |
               +-----------------------+

               |                       |
               v                       v
     [STEP 2A: fg_gc.sh]     [STEP 2B: bg_gc.sh]

               |                       |
               v                       v
     Pauses background GC    Sets up background thread
     threads via sysfs       sleep rates via sysfs

               |                       |
               +-----------+-----------+
                           |
                           v
               [common.sh: begin_test()]
               - Saves a baseline snapshot of sysfs tunables
               - Syncs caches and cleans test folders ($TEST_DIR)
               - Stores initial base metrics in variable $C0
                           |
                           v
               [common.sh: ramlog_start()]
               - Truncates stale UFS trace buffers
               - Spawns ufs_cmd_log tracker in the background
                           |
                           v
               [Execute Core Test Engine Profile]
               - gcload runs disk traffic patterns (append/churn/delete)
                           |
                           v
               [common.sh: ramlog_stop()]
               - Terminates background tracker via standard SIGINT
               - Stores binary hardware trace data logs
                           |
                           v
               [common.sh: end_test()]
               - Pulls ending telemetry snap ($C1) from debugfs
               - Computes relative difference: delta = $C1 - $C0
               - Evaluates assert conditions via need_gt()
               - Outputs values to CSV and restores sysfs profiles
                           |
